# UML diagrams

The `.puml` files are PlantUML source files. Open them with a PlantUML extension in VS Code or paste their contents into a PlantUML renderer to generate diagram images.

Included diagrams:
- `use_case.puml` — actors and system functions
- `class_diagram.puml` — main classes and relationships
- `activity_diagram.puml` — student/admin workflow
- `sequence_diagram.puml` — examination request and evaluation messages
- `deployment_diagram.puml` — browser, Flask server and in-memory data deployment

For an assignment submission, export each diagram as PNG or PDF from PlantUML and insert it into your report.
